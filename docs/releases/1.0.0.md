# 1.0.0

Fan control, joystick lights and Magic Modules for the AYANEO 3 on Bazzite, in the Decky menu.

## What it does

- **Fan:** Auto, Quiet, Manual and a custom Curve, with the CPU temperature and fan speed always in view. 100% at 95 °C in every mode except Auto; the fan goes back to Auto whenever Decky stops.
- **Joystick lights:** Off, Solid, Breathe and Rainbow, five preset colours, your own colour and brightness. Your choice comes back after refitting the modules or waking the device.
- **Magic Modules:** release the left, right or both modules; they switch back on by themselves once refitted.
- If the plugin's background part stops responding, the panel says so instead of showing old values.

## Install

Download `Ayaneo3-Decky.zip`, then in Decky's settings turn on Developer mode and choose **Install Plugin from ZIP File**. Don't unzip it. See [INSTALL.md](../INSTALL.md).

Tested on an AYANEO 3 (Ryzen 7 8840U) with Bazzite 45 and Decky Loader 3.3.1; see [VALIDATION.md](../VALIDATION.md). The HX 370 model has not been tested.
